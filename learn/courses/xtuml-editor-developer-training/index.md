This course teaches you how to become an xtUML Editor developer. It covers installing the required tools, downloading and building the open-source code, and practical exercises that add features to xtUML Editor. The lessons stay in module order. Each video lesson links to its YouTube video. Opening a lesson does not require an account, and the site does not record progress.

The lesson material is shared under [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
