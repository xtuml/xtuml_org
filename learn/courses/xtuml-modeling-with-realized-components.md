Often modeling projects begin with the goal of adding new functionality to an existing implementation. This course describes a method for incorporating an existing implementation as realized components in a model.

The original outline has these four modules, and no lessons are published under them:

1. Introduction to xtUML Modeling
2. Executing Models with Realized components
3. Working with Realized Java Components
4. Working with Realized C components

The lessons and YouTube videos on realized components, realized external entities, and checking realized components are in [Modeling with xtUML, Module 18]({{ '/learn/courses/modeling-with-xtuml/introduction-to-realized-code-integration/' | relative_url }}).
