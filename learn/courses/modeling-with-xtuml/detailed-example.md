Follow the detailed steps to Component Based Test in a hands on BridgePoint session.

- Using the testbenching project.
- Enabling Inter-Project References.
- Copying the example testbench component.
- Add the actual interface to be tested over.
- Modify the example classes to actually perform the tests required.
- Wire up the testbench to the Component Under Test and to the Test Runner.
- Add a test initialization stanza to the setup operation.
