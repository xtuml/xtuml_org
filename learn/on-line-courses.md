The old site offered three guided courses (Modeling with xtUML, xtUML Editor Developer Training, and xtUML Modeling with Realized Components). Those courses tracked progress behind an account, and the lesson text is not in the public export, so the player is not reproduced here.

The same subjects are covered by the open notes and exercises:

- [BridgePoint modeling exercises]({{ '/assets/uploads/2013/04/BridgePoint_xtUML_Modeling_Exercises.pdf' | relative_url }}) (PDF)
- [Action language tutorial]({{ '/learn/action-language-tutorial/' | relative_url }})
- [Model translation exercises](https://github.com/xtuml/training/blob/master/doc-training/notes/Generator_exercises.md)
- [Training courses on GitHub](https://github.com/xtuml/training/tree/master/courses/xtUML-Modeling)

**Modeling with xtUML** was a broad introduction for first-timers and for people strengthening executable, translatable modeling.

**BridgePoint developer training** covered the tool flow used to build BridgePoint itself: installing the developer setup, then designing and testing a change.

**Modeling with realized components** covered action language that calls out to code written by hand.
