How and what SVN client should I download and install for using it in a team? I use a Linux Ubuntu 12.10 x86-32.

---

**keithbrown** · May 1, 2013 at 1:52 am

Hi Domonkos,

When you open the SVN Repository Exploring perspective for the first time you will be presented with a dialog to install and SVN connector.

I recommend the latest SVNKit (currently 1.3.5).

After the connector is installed, you should be able to create an SVN repository connection and begin using your CM system.
