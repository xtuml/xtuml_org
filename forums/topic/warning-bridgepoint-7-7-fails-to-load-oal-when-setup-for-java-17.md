**Clive** · March 6, 2025 at 12:28 am

If attempting to use BridgePoint 7.7 with Java 17: whilst all the graphical parts of a model are loaded and editable, the OAL parts of the model are not and an error is displayed. The (obvious) error does not occur when using java 11.
This information could be added to the “HOW-TO-INSTALL BRIDGEPOINT” instructions. Currently the instructions DO clearly indicate to use Java 11, there are comments that simply say that BP has not been tested for later versions of Java. As Java 17 seems to be the go-to version for several other apps, I felt it would be worthwhile testing.
