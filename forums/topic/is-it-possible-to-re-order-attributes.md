Looking to re-order attributes on the Class Diagram, e.g. move attrib decl from being last (bottom) in list to first (top). Is this possible?

\[Example in case question isn’t clear: I have a class for which I declared a number of descriptive attributes. None forms an identifier. So I added a synthetic ID. It’s now listed at the bottom of the list of attribs. I prefer to show IDs at the top. So I’d like to move it up the list\].

**poj** · March 26, 2013 at 12:08 pm

In the Model Explorer, you can right-click on an attribute and choose “Move Up” and “Move Down” to change the order of the attributes in a class.
