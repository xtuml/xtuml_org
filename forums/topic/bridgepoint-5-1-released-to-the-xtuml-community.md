You may have noticed the news announcement here on xtuml-org.hustlefish-sites.com that [BridgePoint 5.1 is released]({{ '/bridgepoint-5-1-community-edition-released/' | relative_url }}).

The nightly build download is a freely available, full-fledged build of BridgePoint (including eclipse). All you have to do is unzip the package and it is ready use. The nightly build download will move forward as a “bleeding-edge” build constantly as new features and fixes are promoted into the mainline code base.

The xtUML team’s focus with this release is to make BridgePoint a truly open source project that others can contribute to. In addition to that goal, we have add some new features and fixes for end-users as well.
