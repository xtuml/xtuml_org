The One Fact team has updated the version of Redmine that runs the BridgePoint issue tracker at [https://support.onefact.net](https://support.onefact.net)

Some users have experienced “404 – Page not found” errors trying to access the website after the upgrade. Various browsers resolve the issue differently, some things that have worked are:

\* Click a link to the website instead of entering the address in the URL bar
\* Clear the browser cache
