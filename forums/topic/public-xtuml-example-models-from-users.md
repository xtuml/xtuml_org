Greetings Toni,

Yes, the xtuml/models repository ([https://github.com/xtuml/models](https://github.com/xtuml/models)) has example application models and models used for testing the BridgePoint tool. This repository is completely public and open source. We welcome xtUML modelers to fork this repository and submit examples via pull requests.
