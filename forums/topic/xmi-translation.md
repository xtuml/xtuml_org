**cort** · August 26, 2023 at 4:04 pm

Hello. BridgePoint had XMI translation in the past. It was supplied as part of MC-3020 (C model compiler). However, maintenance for it was stopped, and it was removed.

You can actually still read about in the MC-3020 Model Compiler User Guide (here: [https://xtuml.github.io/docs/mcug/ch02.html](https://xtuml.github.io/docs/mcug/ch02.html)).

There is a more recent prototype of BridgePoint/XMI conversion in a project that was intended to operation on Enterprise Architecture models. You can see a youtube demo here: [https://www.youtube.com/watch?v=4RhcDusyIXI](https://www.youtube.com/watch?v=4RhcDusyIXI)

These could be dug up and dusted off if there was a compelling reason.

Kind regards,
Cort
