You can find BridgePoint help from
Help \> Help contents,

As a starting point my recommendation is
BridgePoint UML Suite Help \> Getting start
and
BridgePoint UML Suite Help \> Reference \> The Style Guide to xtuml Modeling/The xtUML Modeling Guide

Hope it helps!
