How to import sample/tutorial to workspace can be done below steps.
サンプルやチュートリアルをworkspaceにimport する方法は下記の通りです。

\[1\] GPS Watch
Help \> Welcome \> Quick start \> Example Application(GPS Watch)

\[2\] MicrowaveOven（電子レンジ）
Help \> Welcome \> Quick start \> Example Application (Microwave Oven)

\[3\] MetaModel (メタモデル)
Help \> Welcome \> Quick start \> Documentation Project- xtUML Metamodel

\[4\] Cheat Sheets (step by step )
Help \> Cheat Sheets \> BridgePoint \> Heart Pacer Case Study
or (もしくは)
Help \> Cheat Sheets \> BridgePoint \> Modeling A Simple System

Good luck!
