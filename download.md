All builds contain a fully functional Eclipse and BridgePoint environment in one package. Nothing else has to be installed first. Unpack the zip where you want the tool to live.

## Install

[HOWTO Install BridgePoint](https://github.com/xtuml/bridgepoint/blob/master/doc-bridgepoint/process/HOWTO-install-bridgepoint.adoc) is the step-by-step guide for macOS, Linux, and Windows. A [short video](https://www.youtube.com/watch?v=Pzyt8mowRUU) walks through the same steps.

## Nightly builds

Nightly builds are the current BridgePoint development line, posted by the build server. They contain the newest code and the least testing. To run a build, execute `{OS-specific path}/bridgepoint`.

Linux, macOS, and Windows builds are listed on the [nightly build index](https://s3.amazonaws.com/xtuml-releases/nightly-build/buildfiles.html).

For an older build, write to support@onefact.net.

## Release builds

Release builds started with BridgePoint v4.2 in November 2014. Highlights for the current release are in the [release notes on GitHub](https://github.com/xtuml/bridgepoint/blob/master/src/org.xtuml.bp.doc/ReleaseNotes/ReleaseNotes.adoc).

## Building BridgePoint

The [Developer Getting Started Guide](https://github.com/xtuml/bridgepoint/blob/master/doc-bridgepoint/process/Developer%20Getting%20Started%20Guide.md) explains how to build BridgePoint from source. See also the [developers page]({{ '/participate/developers/' | relative_url }}).

An Ubuntu 14 virtual machine with the tools and repositories already cloned is available as a [developer appliance](https://s3.amazonaws.com/1f-outgoing/BridgePointDeveloper.ova) (about 5 GB).

## Example models

Application models used in the learning material are in the [xtuml/models](https://github.com/xtuml/models) repository. [HOWTO access git using BridgePoint](https://github.com/xtuml/bridgepoint/blob/master/doc-bridgepoint/process/HOWTO-use-git.adoc) explains how to clone that repository with EGit.
