<td style="border: none; padding: 0in" width="20%"><p><strong>Open Source Development</strong></p></td>
<td style="border: none; padding: 0in" width="80%"><p>The BridgePoint xtUML team has been hard at work<br />
publishing source code and making the development process for<br />
BridgePoint 100% open source and easy to use.</p>
<ul>
<li><p>Models, source code, and binaries for Editor,<br />
Verifier, Model Compilers, and Generator are all now available</p></li>
<li><p>Updated the BridgePoint build toolchain to<br />
make it easier to get set up and use, both locally and on a build<br />
server</p></li>
<li><p>Improved the community accessibility on<br />
[xtUML.org]({{ '/' | relative_url }}) and launched a new<br />
[issue tracker](http://support.onefact.net/)</p></li>
<li><p>Cleaned up lots of heritage IP and<br />
transitioned all source code to Apache 2.0 licensed</p></li>
<li><p>Added support for Linux-based development of<br />
BridgePoint in addition to Windows</p></li>
</ul></td>
</tr>
</tbody>
</table>
