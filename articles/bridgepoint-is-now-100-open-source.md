All of BridgePoint is now Open Source Software.  The full source code and documentation are accessible at [github.com/xtuml](https://github.com/xtuml).  You can download an installable Open Source BridgePoint at [xtuml-org.hustlefish-sites.com/download]({{ '/download/' | relative_url }}).  The Editor, Verifier and Model Compilers are now openly accessible, licensed under Apache 2.0.  See the [full announcement here]({{ '/one-fact-inc-announcement/' | relative_url }} "One Fact Inc Announcement").
